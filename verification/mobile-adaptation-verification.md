# 移动端适配验证记录

## 实施范围

- 登录后全局布局新增 767px 以下抽屉导航，包含全部既有页面、导入、导出和锁定入口；选择页面或点击遮罩后关闭。
- 320-767px 下重排页面标题与操作区，缩减页面和弹窗内边距，保持触控按钮可达。
- 弹窗限制在动态视口内并允许内容滚动，输入控件使用 16px 字号避免 iOS 自动缩放。
- 凭证表格保留全部列和操作，在自身容器横向滚动；触屏下操作按钮始终可见。
- Markdown 长文本、代码块和表格限制在内容区域内，不产生页面级横向滚动。
- 所有移动规则均限定在 `max-width: 767px`，768px 以上沿用既有布局。
